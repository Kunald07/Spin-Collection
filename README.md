# Spin Collection Replica 🌍✨

A modern and visually immersive replica website inspired by the **Spin Collection** luxury travel experience platform.  
Built using **HTML**, **CSS**, **JavaScript**, and **GSAP ScrollTrigger animations**.

This project focuses on elegant layouts, cinematic visuals, smooth scrolling animations, and premium UI aesthetics.

---

## 🚀 Features

- Luxury Travel Website UI
- GSAP Scroll Animations
- ScrollTrigger Effects
- Fullscreen Video Section
- Responsive Layout
- Smooth Image Transitions
- Minimal & Elegant Design
- Interactive Scroll Experience

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger
